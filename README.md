# 🎧 무선 헤드폰 3종 실구매 맞춤 비교 가이드

쿠팡에서 판매 중인 대표 무선 노이즈 캔슬링 헤드폰 3종(**보스 QuietComfort**, **소니 WH-1000XM5**, **애플 에어팟 맥스**)의 가격, 평점, 핵심 장단점 및 사용자 환경별 선택 이유를 비교하는 웹 대시보드입니다.

GitHub Pages를 통해 모바일 및 PC 브라우저에서 인터랙티브하게 열람할 수 있습니다.

---

## 📌 주요 특징
- **사용자 맞춤 4대 기준 분석**:
  - 갤럭시 / 윈도우 PC 병용 최적화 (멀티포인트 2대 동시 연결 지원 여부)
  - 작업 환경(말소리, 키보드, 저주파 엔진음) 소음 차단력 비교
  - 장시간 착용 시 피로도(무게, 쿠션감, 정수리 압박) 평가
  - 30만 원대 실속형 가성비 라인업 검토
- **에메랄드 라군 테마 UI**: 청량하고 가독성 높은 모바일 반응형 디자인
- **인쇄 및 PDF 저장 지원**: 브라우저 인쇄(`Ctrl + P`) 시 웹 레이아웃과 컬러를 유지하며 A4 규격에 맞춤 출력
- **독립형 실행 구조**: 이미지 에셋을 인라인 Base64로 번들링하여 단일 HTML 파일로도 완벽 렌더링

---

## 📂 프로젝트 구조
- `index.html`: GitHub Pages의 메인 웹페이지로 서빙되는 통합 대시보드
- `shopping-compare.html`: 단독 보관 및 공유용 독립 실행형 대시보드
- `bose_qc.jpg`, `sony_wh1000xm5.png`, `airpods_max.jpg`: 제품 원본 에셋
